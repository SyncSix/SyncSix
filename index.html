O projeto

A SyncSix reúne seis alunos do curso de Desenvolvimento de Software Multiplataforma da Fatec Votorantim para o desenvolvimento do Projeto Integrador do semestre. O desafio proposto é construir, para o Grupo Panna, um site voltado à área de Governança — aplicando na prática o conteúdo estudado em cada disciplina do curso.

Cada disciplina do semestre contribui com uma frente do projeto:

  • Algoritmos e Lógica de Programação

    Lógica de programação e estrutura das funcionalidades do sistema.

  • Modelagem de Banco de Dados

    Modelagem e armazenamento das informações de governança.

  • Desenvolvimento Web 1

    Construção do site, do front-end à integração de conteúdo.

  • Design Digital

    Identidade visual, layout e experiência de uso da interface.

  • Engenharia de Software 1

    Levantamento de requisitos, processo e documentação do projeto.

  • Sistemas Operacionais e Redes de Computadores

    Infraestrutura, hospedagem e ambiente de execução do site.
